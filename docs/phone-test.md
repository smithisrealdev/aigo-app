# ทดสอบ AiGo บนมือถือ

เปิดแอปผ่าน Expo Go จากคอมพิวเตอร์ของคุณ ไม่ต้อง build แอปและไม่ต้องตั้งค่า backend (แอปต่อ Supabase `vjblrglalptgdxabteqm` เอง)

## เตรียม

- มือถือ: ติดตั้ง Expo Go รุ่นล่าสุดจาก App Store หรือ Google Play (แอปนี้ใช้ Expo SDK 58 ถ้า Expo Go บอกว่า SDK ไม่ตรง ให้อัปเดต Expo Go)
- คอมพิวเตอร์: Node.js 22 ขึ้นไป และ git
- มือถือกับคอมอยู่ Wi-Fi เดียวกัน (ถ้าไม่ได้ ใช้ `--tunnel` ด้านล่าง)

## เปิดแอป

```bash
git clone https://github.com/smithisrealdev/aigo-app.git
cd aigo-app
git checkout claude/awesome-cori-zvsu1f
npm install
npx expo start
```

- iPhone: เปิดกล้อง สแกน QR ที่ขึ้นใน terminal แล้วกดเปิดใน Expo Go
- Android: เปิด Expo Go แล้วกด Scan QR code
- มือถือไม่อยู่ Wi-Fi เดียวกับคอม: ใช้ `npx expo start --tunnel` แทน
- มี repo อยู่แล้ว: `git fetch origin claude/awesome-cori-zvsu1f` แล้ว `git checkout claude/awesome-cori-zvsu1f` และ `git pull`

## สิ่งที่ควรลอง (ราว 10 นาที)

| ลอง | ควรเห็น |
|---|---|
| เปิดแอปครั้งแรก | หน้า AiGo ไม่มีการ์ดทริปตัวอย่าง แท็บทริปบอกว่ายังไม่มีทริป และมีลิงก์ดูตัวอย่าง |
| พิมพ์ เช่น "อยากไปฮอกไกโด 5 วันกับแฟน ปลายมกราคม ชอบออนเซ็นและของกิน" | AiGo ตอบทีละคำ พูดแทนตัวว่า "ฉัน" ลงท้าย "ค่ะ" มีการ์ดสถานที่พร้อมรูป และถามไม่เกิน 2 ข้อ |
| กดการ์ดเที่ยวบิน ที่พัก หรือร้าน | เปิด Aviasales หรือ Booking.com ตามวันที่ของทริป หรือ Google Maps ราคาบนการ์ดขึ้นต้นด้วย ~ และมีป้าย "AiGo ประมาณ" |
| กด "ให้ AiGo จัดการทั้งหมด" ในตั๋วสรุป | หน้างานขึ้นแผนทีละวัน (ทริป 5 วันราว 30–90 วินาที) งานหาเที่ยวบิน ที่พัก และร้าน บอกจำนวนที่เจอ |
| เปิดแผน | แผนที่ร่าง จุดแวะมีรูป ท้ายแผนมีการ์ดการจองที่ AiGo แนะนำ |
| พิมพ์ในช่อง "บอก AiGo" หรือกด + ระหว่างจุดแวะ | เปิดแชต AI ตอบเรื่องทริปนี้พร้อมการ์ด ไม่ถามใหม่ตั้งแต่ต้น |
| หน้าสถานที่ กด "นำทางไปที่นี่" | เปิด Google Maps |
| ปุ่ม "วันนี้" บนหน้าแผน | ก่อนเดินทางบอกว่าอีกกี่วันและแสดงวันแรก ระหว่างเที่ยวบอกที่ถัดไปและปุ่มนำทาง |
| ปุ่มแชร์บนหน้าแผน | ส่งแผนรายวันเป็นข้อความผ่าน LINE หรือแอปอื่น |
| เปิดโหมดเครื่องบินแล้วเปิดแผน และพิมพ์ในแชต | แผนยังเปิดได้ แชตบอกว่าต่อ AiGo ไม่ได้และมีปุ่มส่งใหม่ |
| เปลี่ยนมือถือเป็นโหมดมืด | ทุกหน้าอ่านง่าย |

## ข้อจำกัดของรุ่นทดลองนี้

- สร้างแผนฟรีได้สัปดาห์ละ 1 ทริปต่อเครื่อง (และ 5 ทริปต่อวันต่อเครือข่าย) ถ้าอยากลองหลายทริป บอกได้ จะรีเซ็ตโควตาให้
- เก็บได้ทีละทริป ทริปใหม่จะแทนทริปเดิม
- ราคาเป็นค่าประมาณของ AI ราคาจริงดูที่เว็บพาร์ตเนอร์ (ต้องมี token ของ Travelpayouts ก่อนจึงจะดึงราคาจริงได้)
- ยังไม่มี: เข้าสู่ระบบ ซื้อทริป แจ้งเตือน ตรวจเวลาเปิดของสถานที่ (ทุกที่ขึ้นว่า "ยังไม่ได้ตรวจ") และแก้แผนด้วยข้อความ ปุ่มเหล่านี้บอกตรงๆ ว่ายังไม่เปิด
- รูปมาจาก Wikipedia และ Wikimedia Commons บางที่ไม่มีรูป (ขึ้นเป็นช่องสี) หรือได้รูปเมืองแทน
