# แอปลื่นและสวย: ค่าการเคลื่อนไหวของ Animate UI, ทุกปุ่มตอบ, โครงร่างระหว่างโหลด และ 3 จุดว้าว — design

วันที่ 21 พ.ย. 2026 · สถานะ: เจ้าของอนุมัติแล้ว ("ทำเลย") เขียนโค้ดเสร็จตาม `docs/superpowers/plans/2026-11-21-smooth-motion.md` รอเจ้าของดูบน iPhone (ต้อง build ใหม่ เพราะเพิ่ม Skia)

## ทำไม

เจ้าของอยากให้แอป "smooth ที่สุด และสวย" มีจุดที่ว้าว ใช้แนวของ Animate UI (สกิลที่ติดตั้งไว้ใน `.claude/skills/animate-ui`) และสกิล smooth-ux

## ที่เจ้าของตัดสินแล้ว

- แนวทาง A: คอมโพเนนต์ของ AiGo เป็นฐานเหมือนเดิม แอนิเมชันเขียนเองด้วย Reanimated ตามค่าของ Animate UI, Reacticx เฉพาะจุดที่อยากให้ว้าว, Lottie สำหรับภาพประกอบเมื่อมีไฟล์, `@rn-primitives` เมื่อต้องการหน้าต่างหรือเมนู (ไม่ย้ายไป Tailwind/NativeWind)
- จุดว้าว 3 จุด: 1) ตอน AiGo กำลังวางแผน 2) ตอนแผนเสร็จ 3) เปิดแอปครั้งแรก
- ทำตามดีไซน์ที่มีเลย เสร็จแล้วอัปเดตแคนวาสให้ดู
- ลบทริป: ยืนยันก่อนแล้วหายทันทีเหมือนเดิม
- ของเสริม: โครงร่างระหว่างโหลด, toast บอกผลที่ไม่เห็นบนจอ, ความคืบหน้าของแผนขยับนุ่มๆ

## เป้าหมาย

1. ทุกการเคลื่อนไหวใช้ค่าชุดเดียว (`src/theme/motion.ts`) ตามค่าของ Animate UI: กดปุ่มสปริง 550/30 ยุบ 0.97 (การ์ดและแถว 0.985), เนื้อหาเข้าสปริง 200/20, จัดตำแหน่งใหม่ 500/40, เลือกแท็บหรือชิป 300/30, แถบคืบหน้า 300/35, toast 280/24 จาก 0.96, เครื่องหมายสำเร็จ 500/24, แผ่นลาก 0.4 วินาทีเส้นโค้งลิ้นชัก
2. "ลดการเคลื่อนไหว" อ่านค่าสดทั้งแอป: เนื้อหาจางเข้าโดยไม่ขยับ แอนิเมชันวนหยุด
3. แผ่นลากในหน้าแผนที่ลากบนเธรดหน้าจอ (react-native-gesture-handler) ไม่กระตุกเมื่อแอปทำงานหนัก
4. ทุกปุ่มที่รอเซิร์ฟเวอร์มีสถานะกำลังทำ: เพิ่ม "ออกจากระบบ" และ "ลบบัญชี"
5. โครงร่างระหว่างโหลด: รูปสถานที่มีแสงกวาดระหว่างรอรูป และวันที่ AiGo กำลังวางขึ้นเป็นโครงร่างรูปทรงเดียวกับแถวรูปจริง
6. แผนเสร็จตอนอยู่หน้าอื่น ขึ้น toast บอก
7. จุดว้าว 1: หน้างานของ AiGo ระหว่างวางแผน มีลูกพลังงาน (EnergyOrb ของ Reacticx) สีของแอป และเลขวันที่หมุนเปลี่ยน (NumberFlow ของ Reacticx)
8. จุดว้าว 2: แผนเสร็จระหว่างดูอยู่ กระดาษสีระเบิดครั้งเดียว เครื่องหมายสำเร็จเด้ง และสั่นเบาๆ (haptic)
9. จุดว้าว 3: หน้าแนะนำแอป ภาพเลื่อนช้ากว่าข้อความ (parallax) ข้อความค่อยๆ ขึ้น จุดบอกหน้ายืดตามนิ้ว ทั้งหมดผูกกับการเลื่อนบนเธรดหน้าจอ

## ไม่ทำ

- คอมโพเนนต์ของ Animate UI (เป็นของเว็บ) และเอฟเฟกต์เบลอ (หนักบนมือถือ)
- Lottie ในรอบนี้: ยังไม่มีไฟล์แอนิเมชันของ AiGo จะเพิ่มเมื่อมีไฟล์ (เช่นตัวละครที่นักออกแบบทำ)
- Rive, หน้าเปลี่ยนแบบจาง (ใช้การเปลี่ยนหน้าแบบ native เดิม)

## ห้ามเกิด

- อะไรที่เคลื่อนไหวแล้วทำให้หน้าจัดตำแหน่งใหม่ทุกเฟรม (ใช้ transform กับ opacity เท่านั้น ยกเว้นแถบคืบหน้าเล็ก)
- แอนิเมชันวน (ลูกพลังงาน แสงกวาด) เล่นต่อตอนออกจากหน้า หรือตอนเปิดลดการเคลื่อนไหว
- กระดาษสีเล่นซ้ำทุกครั้งที่เปิดหน้าของแผนที่เสร็จแล้ว (เล่นเฉพาะตอนเปลี่ยนจากกำลังวางเป็นเสร็จ)
- เว็บพังเพราะ Skia (เว็บใช้ลูกโลหะแบบ Reanimated แทน)

## ข้อจำกัด

- Expo SDK 58, Reanimated 4.7, gesture-handler 3.3, React Compiler (ใช้ `.get()/.set()` ของ shared value)
- EnergyOrb ใช้ `@shopify/react-native-skia` (ต้อง build แอปใหม่หนึ่งครั้ง) ติดตั้งด้วย `npx expo install`
- โค้ด Reacticx (MIT) คัดลอกเข้าโปรเจกต์ตามแบบของ Reacticx เก็บประกาศสัญญาอนุญาตไว้
- หน้าตาบนเครื่องจริงตรวจที่ iPhone ของเจ้าของ เว็บตรวจได้เฉพาะส่วนที่ไม่ใช่ Skia

## ที่ผมตัดสินเอง (เจ้าของแก้ได้)

- กระดาษสีเขียนเองด้วย Reanimated (Reacticx ไม่มี) สีของแอป 36 ชิ้น 1.6 วินาที
- หน้าแนะนำแอปเขียนเองด้วย Reanimated ผูกกับการเลื่อน แทน parallax-carousel ของ Reacticx เพราะต้องคงเลย์เอาต์และข้อความเดิม
- ลูกพลังงานหยุดเมื่อออกจากหน้า เมื่อแผนไม่ได้กำลังวาง และเมื่อเปิดลดการเคลื่อนไหว (แสดงภาพนิ่ง)
- หลังลองบนเบราว์เซอร์: shader เดิมของ EnergyOrb บวกแสงเพิ่ม บนพื้นสว่างของแอปจึงกลายเป็นสีขาว และจางจนเกือบหายทุกไม่กี่วินาที จึงปรับ shader ให้ผสมสีแบบปกติ มีแกนสว่าง แขนสีหมุนรอบ และไม่จางหาย (ใช้ได้ทั้งธีมสว่างและมืด) สีส้มหลัก ทอง ชมพู
- เครื่องหมายสำเร็จกับกระดาษสีอยู่กลางจอทับทุกอย่าง (ไม่รับการแตะ) แล้วหายเองในราว 2 วินาที เพราะหน้างานเลื่อนตามของใหม่ลงล่างสุด ถ้าวางไว้บนสุดจะไม่เห็นตอนแผนเสร็จ
- จุดบอกหน้าในหน้าแนะนำแอปเป็นแถบเข้มเลื่อนตามนิ้วบนจุดคงที่ (ยืดนิดหน่อยระหว่างทาง) แทนการยืดจุดแต่ละจุด เพราะยืดวงกลมจะได้วงรี
- โครงร่างของวันถัดไปใช้หัวข้อ "วันที่ N" จริง (รู้เลขวันอยู่แล้ว) กับโพลารอยด์เปล่า 3 ใบ
- แอนิเมชันวนทุกตัว (ตัว AiGo ลอย จุดกระพริบ จุดคิด แสงกวาด ลูกพลังงาน) หยุดเมื่อหน้าของมันไม่อยู่บนจอ
